# Repo Knowledge

Incremental review knowledge for a large repository.

Rules:

- Analyze one module per run.
- Preserve accumulated knowledge.
- Mark assumptions and unknowns.
- Prefer partial truth over broad claims.
- Keep review artifacts traceable to selected files.

Layers:

- `maps/`: where things are and how modules relate.
- `modules/`: one document per analyzed module.
- `patterns/`: reusable engineering mechanisms.
- `skills/`: procedural engineering workflows.
- `reviews/`: per-run review records.
- `_inbox/`: unresolved notes and TODOs.
