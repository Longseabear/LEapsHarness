# 파트장 주간 메모

## 플랫폼 파트
- API 게이트웨이 인증 캐시 작업은 개발 80% 완료. 평균 인증 처리 시간이 210ms에서 145ms로 내려감.
- 캐시 무효화 조건에서 QA가 버그 2건 발견. 사용자 권한 변경 직후 3분 동안 오래된 권한이 남는 케이스.
- 다음 주 수요일까지 무효화 이벤트를 메시지 큐로 분리하는 패치를 끝낼 예정.

## 데이터 파트
- 고객 세그먼트 배치가 기존 2시간 40분에서 1시간 55분으로 단축됨.
- 다만 신규 가입자 0.6%가 세그먼트 미분류로 남는 문제 확인. 원인은 가입 이벤트 지연으로 추정.
- 세그먼트 미분류자는 임시로 기본군에 포함했고, 다음 주에는 이벤트 지연 원인을 추적 예정.

## 운영 파트
- 장애 알림 라우팅을 정리해서 야간 오탐 11건 중 7건을 제거.
- 온콜 담당자 자동 배정은 정책 합의가 끝났지만, 휴가자 예외 처리가 아직 없음.
- 다음 주 금요일까지 휴가자 예외와 수동 override 기능을 넣을 계획.

## 요청
- 인증 캐시의 권한 변경 반영 허용 지연 시간을 0분으로 둘지, 최대 1분까지 허용할지 결정 필요.
- 고객 세그먼트 미분류 0.6%를 다음 주 실험 대상에서 제외해도 되는지 확인 필요.
